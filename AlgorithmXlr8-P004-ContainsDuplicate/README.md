# Contains Duplicate

**Difficulty:** `Easy`

## Problem

Given an integer array nums, return true if any value appears at least twice, and false if every element is distinct.

Read n on the first line of standard input, then n space-separated integers on the second line. Print true or false to standard output.

## Examples

### Example 1

**Input**
```
4
1 2 3 1
```
**Output**
```
true
```

**Explanation:** The value 1 appears twice.

### Example 2

**Input**
```
4
1 2 3 4
```
**Output**
```
false
```

**Explanation:** Every value is distinct.

### Example 3

**Input**
```
10
1 1 1 3 3 4 3 2 4 2
```
**Output**
```
true
```

**Explanation:** Several values repeat multiple times.
