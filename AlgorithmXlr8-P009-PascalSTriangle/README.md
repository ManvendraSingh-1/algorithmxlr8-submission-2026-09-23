# Pascal's Triangle

**Difficulty:** `Easy`

## Problem

Given an integer numRows, return the first numRows of Pascal's triangle.

In Pascal's triangle, each number is the sum of the two numbers directly above it, and every row starts and ends with 1.

Read numRows from standard input. Print numRows lines to standard output, one per row, with each row's numbers separated by a single space.

## Examples

### Example 1

**Input**
```
numRows = 5
```
**Output**
```
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

**Explanation:** The first 5 rows of Pascal's triangle, each number formed by summing the two numbers above it.

### Example 2

**Input**
```
numRows = 1
```
**Output**
```
1
```

**Explanation:** A single row, just the value 1.

### Example 3

**Input**
```
numRows = 2
```
**Output**
```
1
1 1
```

**Explanation:** The second row is 1 1, since a row's first and last values are always 1.
